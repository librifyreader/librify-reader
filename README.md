# Librify Reader 📚

O **Librify Reader** é um aplicativo leitor moderno para Android, desenvolvido nativamente em Kotlin com foco em arquitetura limpa, alta performance e acessibilidade.

---

## 🚀 Funcionalidades

* **Leitura Fluida:** Suporte a múltiplos formatos de documentos e e-books.
* **Acessibilidade:** Compatível com TalkBack, suporte a temas de alto contraste (incluindo modo escuro e sépia) e redimensionamento dinâmico de fontes.
* **Desempenho:** Carregamento otimizado com Coroutines, Flow e Paging 3 para leitura de arquivos densos sem travamentos.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Kotlin
* **IDE:** Android Studio
* **Arquitetura:** Clean Architecture + MVVM / MVI
* **UI:** Jetpack Compose / Material Design 3
* **Injeção de Dependência:** Hilt
* **Async & Data:** Kotlin Coroutines, Flow, Room Database
